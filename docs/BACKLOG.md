```
1. pytest tests/ -q                    → 全绿（数字记下来）

6. 若改了测试 → 必须重生成评审包（`_pytest_count()` 会变 ⇒ 必 STALE）

   第二次内容对了但进度提示行还留着"进行中"；第三次指纹才不变
```

**纪律提醒**（都是踩过的坑）：
- `--check OK` **不**证明源码实现仍在（禁用一段实现照样绿，§47.4）。要证明用针对性测试 + 变异。
- `--full` 若报一堆红，先确认是不是"一边改文件一边跑"造成的假红。
- 加测试 ⇒ `_pytest_count()` +1 ⇒ 评审包必 STALE ⇒ 要么重生成，要么这一步不并入批次。
- 判据的期望值**必须先跑再写**（§61.7 / §63.7 两次凭印象预填都写错了）。
