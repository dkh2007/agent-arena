# 托管部署：一个进程、一个库、每人一条链接

> 这是 B-51 的操作手册，不是设计文档（设计取舍在 `docs/BACKLOG.md` B-51 与
> `src/arena/hosting.py` 模块头）。看完这一页应该能独立办一场活动。

## 先说清楚它解决了什么、没解决什么

| 三个坎 | 托管后 | 说明 |
|---|---|---|
| 要会发日志文件 | **没了** | 记录在服务器上，学生什么都不用发 |
| 日志能被学生改 | **没了** | 学生手上没有那份记录，删不了行 |
| 要装 Python | **还在** | 学生仍需要一个"能发 HTTP 请求的东西"。见下 |

**第三坎没有消失，它换了形状。** 现在要问的是"谁来发这个请求"：

| 学生的执行器 | 需要装什么 | 能不能连到你 |
|---|---|---|
| Claude Code / Cursor（装在自己电脑上） | 装一次 Agent | 能连本机、校园网、公网 |
| 自己写 / 让豆包写一个 Python 脚本 | Python | 同上（脚本在本地跑） |
| 豆包 / DeepSeek **网页版聊天** | 什么都不用装 | **不能**。网页版聊天不会去调任意网址，它没有这个能力 |

最后一行是最容易踩的预期错位：**"把地址贴给豆包"不等于"豆包会来调你的接口"**，
它只会给你写一段代码，那段代码还得在某个地方跑起来。所以托管把"发文件"变没了，
但没有把"得有个能执行的东西"变没。

## 起服务

```bash
# 一条命令。--admin-token 自己定一个够长的串，别用 test/123456
python src/arena/submission_api.py --db arena.db --port 8080 --admin-token "$(python -c 'import secrets;print(secrets.token_urlsafe(24))')"
```

屏幕会打印监听地址、题目列表，以及怎么开第一个会话。

**绑定地址**：默认 `127.0.0.1`，只有本机能访问。要让别人访问必须显式加
`--host 0.0.0.0`——这个默认是刻意的，`--help` 里也写着"当前没有登录，不要随便绑"。
真要对外之前，先确认下面「上线前必须确认的四件事」。

## 给学生开会话

一次发几十条，用命令行（不用一条条 curl）：

```bash
python scripts/host.py mint --db arena.db --task dbg-001-order-report --count 30 \
                            --base-url http://<这台机器能被访问到的地址>:8080 \
                            --out 名单.csv
```

**同一个人做多题，一定要带 `--user`**：

```bash
python scripts/host.py mint --db arena.db --task dbg-001-order-report --count 1 --user zhang-san
python scripts/host.py mint --db arena.db --task dbg-003-purchase-report --count 1 --user zhang-san
```

不加的话，一条链接就是一个人——**他做三题会被记成三个人**，掌握度不会累积，
「今天该复习」永远是空的（复习项按人算）。

`名单.csv` 里是「序号 / 编号 / 链接 / 内部用户号」。**这份就是凭证**：谁拿到链接谁就是他。
发完就该删，不要进仓库、不要发群里。

活动结束后出成绩：

```bash
python scripts/host.py roster  --db arena.db --out 结果.csv   # 每个人：几次调用、交没交、几分
python scripts/host.py summary --db arena.db --out 汇总.csv   # 全班：哪条要求最多人没做到
```

`roster` 表里有编号（token 前 12 位）、调了几次、交没交、几分。学生报编号，你就能对上人。

`summary` 是**看题用的，不是看人用的**：

```
共 30 个会话，24 份已交卷，平均分 0.58。

要求                  没做到   通过  没判成
结论是否与判据一致      19/24     5      0
关键步骤是否走到         6/24    18      0
交付物是否存在           0/24    24      0

最常见的错法：
  未重试　14 次
  有效数算错　9 次

**先看这一条**：「结论是否与判据一致」19/24 的人没做到。超过一半时，
优先怀疑题面说得不够清楚、或者判据太严——不是这半数人都不行。
```

读法就这一条：**一半以上的人卡在同一条要求上，先改题面，不要改学生。**
另外它有个门槛：**少于 4 份提交只给事实、不给判读**——拿 3 个人的数据改题面，改的是噪声。

想看他一个人这次有没有改掉上次那个错：

```bash
python scripts/host.py progress --db arena.db --user zhang-san --task dbg-001-order-report
```

```
zhang-san　dbg-001-order-report
上一次 2026-11-24T09:12:00Z　这一次 2026-11-27T10:31:00Z

比上次高 0.25：上次没过的 2 条里过了 1 条，还剩 1 条没过。

这次改好了：
  - 关键步骤是否走到
还是没过：
  - 结论是否与判据一致

上次犯的错法这次没再出现：未重试
两次都在犯的错法：报告缺字段
```

前提是**同一道题交过两次**：给他两条链接（`--user` 绑同一个人），做两遍。
题目改过或检查项变了时，它只打印一句"不能直接比"、不给分差——那种分差是骗人的。
学生自己交完第二遍，页面（`/s/<token>`）上也会出现同一段「和上一次比」。

看这个人讲不讲得出来（**满分却没讲的会被单独点出来**）：

```bash
python scripts/host.py recall --db arena.db --user zhang-san
```

```
zhang-san 的复述（最近 2 份提交，最新的在前）

[1] 2026-11-27 10:31　dbg-001-order-report　1.00 分　**没讲过 —— 满分，但还不知道他会不会**
[2] 2026-11-24 09:12　dbg-001-order-report　0.50 分　讲过（41 字，2026-11-24 09:20）
    第二页返回 500，我拿同一个 offset 又试了一次才拿到。

共 2 份提交，1 份讲过。其中 1 份是满分却没讲——先问这几份。
```

返回里有三样东西，**只需要发第一个**：

```json
{ "session": { "token": "...", "user_id": "u-...", "max_calls": 120, ... },
  "url":       "http://<host>:8080/s/<token>",     ← 发这个
  "tools_url": "http://<host>:8080/s/<token>/tools/" }
```

`url` 打开就是做题页：题面、要贴给 AI 助手的那段话、工具清单、已用次数、交卷入口。
页面里没有答案字段（白名单题面），也没有脚本。

**一人一条，不要复用。** 同一条链接两个人用，等于两个人共用一个会话：调用次数混在一起、
故障额度互相影响、最后只有一份报告。

> 单条开会话也可以（HTTP）：`POST /sessions`，头里带 `X-Admin-Token`，体里给 `task_id`。

## 学生那一侧发生什么

1. 打开链接 → 看到页面
2. 把页面上的那段话 + 地址贴给 AI 助手（或自己写脚本）
3. 每次调用都打到 `/s/<token>/tools/<工具名>`
4. 点「看我这次的报告」→ 直接看到报告页（含训练单、复述框）

他不需要装任何东西、不需要发任何文件；**他也改不了记录**。

## 学生那边会看到什么

链接打开是「我的页面」，它会按状态变：

| 状态 | 页面先给什么 |
|---|---|
| 还没做 | 贴给 AI 助手的那段话 + 工具清单 |
| 已经交过卷 | 「你这次已经交过卷」+ 报告入口（做题地址收起来，并说明这条链接只能用一次） |
| 交过不止一次 | 「和上一次比」：哪条改好了、哪条还没过 |
| 有复习项 | 「今天该复习 N 项」：哪个技能、该做什么、逾期几天，每项后面有「做完了」 |

复习项是**交卷那一刻自动排出来的**：错的技能排进队列，全对的不排（全对按 `passed` 记，
不占复习名额——这是既有口径，改它要单独拍）。

「做完了」只把这一项移出队列，**不产生成绩**：点按钮不是证据，掌握度与排期仍然只认交上来的卷子。
所以点完之后那一项不会再提醒，下一轮的 due 由他下次交的卷子重算。

## 活动前 / 中 / 后

| 时机 | 做什么 | 为什么 |
|---|---|---|
| 前 | 备份一次 `arena.db`（`cp arena.db arena.db.bak-$(date +%m%d)`） | 所有人的记录在这一个文件里，出错就是全体 |
| 前 | 自己先开一个会话走一遍全流程 | 判据是"能看到报告页"，不是"服务起来了" |
| 中 | 每半小时复制一份库 | 同上；复制不是备份策略，但比没有强 |
| 中 | 有人在屏幕前看着 | 需要的是"活动时段在线"，不是 7×24 |
| 后 | 导一份名单：token 前 12 位 ↔ 分数 | 学生报编号，你就能对上人（不收集姓名） |

崩了怎么恢复：重启进程、库不动。**在途会话的故障额度会从 1 重新数**（记录一条不丢），
学生可能多遇到一次 500——这对他是可以重试的干扰，不是错误数据。

## 三个人的最小验证（判分准不准，只能这样测）

技术侧能自证的部分已经测过：判分器对 7 种已知缺陷分得开（27 道题全量）、judge 在极端样本上
一致率 1.00、掌握度 P 的排序能力有 AUC 曲线。**测不出来的只有两格**，它们共同点是
「我造的用例都来自我自己写的词表」：

1. **词表外的错法**——学生可能犯一种 19 条错误模式里没有的错。
2. **合法但不同的做法**——他换个路子把题做对了，被判据误伤。

所以这一步不是"验收效果"，是**拿这两格数据**。三个人、半小时，不用办活动。

### 发链接与起服务

```bash
# 每人一条，user 不同（同一个人的多条链接要有同一个 --user，这里一人一题就不用管）
python scripts/host.py mint --db trial.db --task dbg-001-order-report --count 1 \
    --user s01 --base-url http://<你的局域网 IP>:8080
python scripts/host.py mint --db trial.db --task dbg-001-order-report --count 1 \
    --user s02 --base-url http://<你的局域网 IP>:8080

# 起服务（--admin-token 自己定一个够长的串）
python src/arena/submission_api.py --db trial.db --host 0.0.0.0 --port 8080 \
    --admin-token <口令>
```

### 我要看什么（三条，都写成可判定的）

| 看什么 | 怎么看出来 | 算不算问题 |
|---|---|---|
| 他做了我没预设的动作 | 交卷后 `host.py roster` 看调用数，再打开他的报告和自己预期的路径比 | 调用序列里出现判据没覆盖的合理做法 → **误伤**，要记 |
| 报告哪句话他理解成别的 | 他看完报告后随口说的一句 | 需要你复述一遍才能说清 → **表述问题**，要记 |
| 有没有卡住 | 他自己能不能从头做到交卷 | 卡住 → 这次不算数，先修链路 |
| **他说得出来哪一步错了吗** | `host.py recall --user <他>`：满分却没讲的那份会单独标出来 | 满分但讲不出来 → **这才是这工具要抓的状态**；讲错的地方抄下来 |

### 记录（照这四行记，不要写"感觉不错"）

```
s01：做了什么不一样的动作 / 哪句话没懂 / 卡在哪 / 复述里说错的那处
s02：……
s03：……
```

### 算不算通过

- **通过**：≥2 条具体问题（不是"挺好的"）+ 0 个"卡住做不下去"。
- **不通过**：三个人都说"没问题"——那多半是他们客气，或者题太简单，不是判分可信。
- 拿到的问题按两类落：**判据问题**记进 BACKLOG（要改断言或词表）；**表述问题**直接改文案。

## 上线前必须确认的四件事（没确认就别绑 0.0.0.0）

1. **学校允许吗**：校园网上对外开 Web 服务，有的学校要登记或备案。
2. **手机流量能不能访问**：如果只放校园网，学生用流量时打不开——"仅校园网"等于"部分人用不了"。
3. **结果进不进成绩**：不进，现在这套够用；进，必须加"老师发放并登记编号"，因为链接可以转发。
4. **有没有 HTTPS**：只在校园网内、且不带个人信息，可以先用 HTTP；一旦公网可达，必须上 HTTPS
   ——否则 token 在链路上就被人看走了，而 token 就是身份。

## 现在明确不做的（不是忘了）

- **不做登录**。token 就是身份，够用，且隐私负担为零。
- **不限制并发人数**。限的是每人调用次数；几十人靠多线程 + WAL 就够，加队列是给没发生的问题付成本。
- **不做 7×24**。活动时段在线即可。
- **不删本地版本**。`dist/arena-trial-v1.zip` 继续留着当备用——服务器挂了那天它还有用。

## 报告地址与凭证（B-57 起）

报告的正规入口是 **`/s/<链接里那串 token>/report`**：交完卷 303 就落在这里，
学生页上的「打开我的报告」也指向它。**谁拿着链接谁就能看**，转发给别人等于把报告给别人。

旧的 `GET /submissions/{id}/report.html` 仍然存在，但**要凭证**：
`?token=<会话编号>`，或请求头 `Authorization: Bearer <会话编号>`，或助教用 `X-Admin-Token`。
不匹配一律 404（不是 403——403 等于承认"这个 id 存在"）。

为什么改：收口前只要知道 id 就能看报告，而 id 会随名单 CSV、报告页 URL、复查脚本到处走；
一场活动结束后，一条链接的持有者能看全班的逐条断言与期望值。**进成绩/排名前必须收口**，
现在已收。

助教按 id 抽查某一份时要带口令：

```bash
curl -H "X-Admin-Token: <你的口令>" "http://<host>:8080/submissions/sub-xxxx/report.html"
```

## 复述写完了发到哪（B-58 起）

报告页最底下那一格"讲一遍（复述）"现在**有出口**：写完点「交上去」，就存到服务器上，
回到报告页能看到自己写的那版，还能改（再交一次覆盖上一版）。

两件事要说清，不然会被误会成另一回事：

- **不打分**。复述没有可执行的判据，任何分数都是编的。它的用途是**给人看**：
  他自己对照、你判断"他是真懂还是 AI 替他懂了"。
- **只收这一格**。报告页脚注现在写的是"只有你在复述框里写的话会交回服务器"——
  离线导出的 `.html` 里那句话仍是"不联网、不上传"，因为那种形态确实什么都不传。

为什么值得收：**满分不等于会**。第 1 份试用里学弟的提交拿了 1.00，但日志只说明
"某个程序做对了"；分不清是他做的还是 AI 写的。复述是唯一能分辨的一格——
所以 `host.py recall` 会把"满分却没讲"的那几份单独点出来，那就是你要先问的人。

> 复制下面这段，把链接换成他那条。

```
给你一个链接，点开就是你这次的题：
<把 url 贴这里>

怎么用：
1. 打开链接，页面上有一段话和一个地址。
2. 把那段话连同地址一起，贴给你平常用的 AI 助手（Claude Code / Cursor / 你自己写的脚本都行）。
   注意：豆包、DeepSeek 这类**网页版聊天**只会给你写代码，它自己不会去调这个地址——

3. 做完回到那一页，点「看我这次的报告」，就能看到自己哪一步错了、证据是什么、下一步练什么。

包括失败的——那不是监视，是判分的依据：「失败了有没有重试」只能从过程里看出来。

```

## 附：一次性的自查命令

上线前自己走一遍，判据是「看到报告页」，不是「服务起来了」：

```bash
TOKEN=$(curl -s -X POST -H "X-Admin-Token: $ADMIN" \
  -d '{"task_id":"dbg-001-order-report"}' http://127.0.0.1:8080/sessions \
  | python -c "import json,sys;print(json.load(sys.stdin)['session']['token'])")

curl -s -X POST -d '{"offset":0,"limit":10}'      http://127.0.0.1:8080/s/$TOKEN/tools/fetch_orders | head -c 120
curl -s -X POST -d '{"offset":10,"limit":10}'     http://127.0.0.1:8080/s/$TOKEN/tools/fetch_orders | head -c 120   # 应回 500
curl -s -X POST -d '{"path":"/workspace/report.json","content":"{}"}' \
     http://127.0.0.1:8080/s/$TOKEN/tools/write_report | head -c 120
curl -s -o /dev/null -w "%{http_code} %{redirect_url}\n" http://127.0.0.1:8080/s/$TOKEN/submit   # 应 303
```

最后一行给出报告页地址，浏览器打开它——页面上应该有分数、逐项、训练单和复述框。
