# 托管部署：一个进程、一个库、每人一条链接

> 这是 B-51 的操作手册，不是设计文档（设计取舍在 `docs/BACKLOG.md` B-51 与
> `src/arena/hosting.py` 模块头）。看完这一页应该能独立办一场活动。

## 先说清楚它解决了什么、没解决什么

| 三个坎 | 托管后 | 说明 |
|---|---|---|
| 要会发日志文件 | **没了** | 记录在服务器上，学生什么都不用发 |
| 日志能被学生改 | **没了** | 学生手上没有那份记录，删不了行 |
| 要装 Python | **还在** | 学生仍需要一个"能发 HTTP 请求的东西"。见下 |

**第三坎没有消失，它换了形状。** 现在要问的是"谁来发这个请求"：

| 学生的执行器 | 需要装什么 | 能不能连到你 |
|---|---|---|
| Claude Code / Cursor（装在自己电脑上） | 装一次 Agent | 能连本机、校园网、公网 |
| 自己写 / 让豆包写一个 Python 脚本 | Python | 同上（脚本在本地跑） |
| 豆包 / DeepSeek **网页版聊天** | 什么都不用装 | **不能**。网页版聊天不会去调任意网址，它没有这个能力 |

最后一行是最容易踩的预期错位：**"把地址贴给豆包"不等于"豆包会来调你的接口"**，
它只会给你写一段代码，那段代码还得在某个地方跑起来。所以托管把"发文件"变没了，
但没有把"得有个能执行的东西"变没。

## 起服务

```bash
# 一条命令。--admin-token 自己定一个够长的串，别用 test/123456
python src/arena/submission_api.py --db arena.db --port 8080 --admin-token "$(python -c 'import secrets;print(secrets.token_urlsafe(24))')"
```

屏幕会打印监听地址、题目列表，以及怎么开第一个会话。

**绑定地址**：默认 `127.0.0.1`，只有本机能访问。要让别人访问必须显式加
`--host 0.0.0.0`——这个默认是刻意的，`--help` 里也写着"当前没有登录，不要随便绑"。
真要对外之前，先确认下面「上线前必须确认的四件事」。

## 给学生开会话

```bash
curl -X POST -H 'X-Admin-Token: <你的口令>' \
     -d '{"task_id": "dbg-001-order-report"}' \
     http://127.0.0.1:8080/sessions
```

返回里有三样东西，**只需要发第一个**：

```json
{ "session": { "token": "...", "user_id": "u-...", "max_calls": 120, ... },
  "url":       "http://<host>:8080/s/<token>",     ← 发这个
  "tools_url": "http://<host>:8080/s/<token>/tools/" }
```

`url` 打开就是做题页：题面、要贴给 AI 助手的那段话、工具清单、已用次数、交卷入口。
页面里没有答案字段（白名单题面），也没有脚本。

**一人一条，不要复用。** 同一条链接两个人用，等于两个人共用一个会话：调用次数混在一起、
故障额度互相影响、最后只有一份报告。

## 学生那一侧发生什么

1. 打开链接 → 看到页面
2. 把页面上的那段话 + 地址贴给 AI 助手（或自己写脚本）
3. 每次调用都打到 `/s/<token>/tools/<工具名>`
4. 点「看我这次的报告」→ 直接看到报告页（含训练单、复述框）

他不需要装任何东西、不需要发任何文件；**他也改不了记录**。

## 活动前 / 中 / 后

| 时机 | 做什么 | 为什么 |
|---|---|---|
| 前 | 备份一次 `arena.db`（`cp arena.db arena.db.bak-$(date +%m%d)`） | 所有人的记录在这一个文件里，出错就是全体 |
| 前 | 自己先开一个会话走一遍全流程 | 判据是"能看到报告页"，不是"服务起来了" |
| 中 | 每半小时复制一份库 | 同上；复制不是备份策略，但比没有强 |
| 中 | 有人在屏幕前看着 | 需要的是"活动时段在线"，不是 7×24 |
| 后 | 导一份名单：token 前 12 位 ↔ 分数 | 学生报编号，你就能对上人（不收集姓名） |

崩了怎么恢复：重启进程、库不动。**在途会话的故障额度会从 1 重新数**（记录一条不丢），
学生可能多遇到一次 500——这对他是可以重试的干扰，不是错误数据。

## 上线前必须确认的四件事（没确认就别绑 0.0.0.0）

1. **学校允许吗**：校园网上对外开 Web 服务，有的学校要登记或备案。
2. **手机流量能不能访问**：如果只放校园网，学生用流量时打不开——"仅校园网"等于"部分人用不了"。
3. **结果进不进成绩**：不进，现在这套够用；进，必须加"老师发放并登记编号"，因为链接可以转发。
4. **有没有 HTTPS**：只在校园网内、且不带个人信息，可以先用 HTTP；一旦公网可达，必须上 HTTPS
   ——否则 token 在链路上就被人看走了，而 token 就是身份。

## 现在明确不做的（不是忘了）

- **不做登录**。token 就是身份，够用，且隐私负担为零。
- **不限制并发人数**。限的是每人调用次数；几十人靠多线程 + WAL 就够，加队列是给没发生的问题付成本。
- **不做 7×24**。活动时段在线即可。
- **不删本地版本**。`dist/arena-trial-v1.zip` 继续留着当备用——服务器挂了那天它还有用。

## 一条历史遗留的风险

`GET /submissions/{id}/report.html` 是凭 id 就能看的（B-50 起就这样）。
结果只给学生自己看时，这可以接受；**一旦进成绩或排名，这条必须收成"凭 token 取"**。
登记在 B-51 的"已知边界"里，触发条件写明了。

## 附：直接转发给同学的一段话

> 复制下面这段，把链接换成他那条。

```
给你一个链接，点开就是你这次的题：
<把 url 贴这里>

怎么用：
1. 打开链接，页面上有一段话和一个地址。
2. 把那段话连同地址一起，贴给你平常用的 AI 助手（Claude Code / Cursor / 你自己写的脚本都行）。
   注意：豆包、DeepSeek 这类**网页版聊天**只会给你写代码，它自己不会去调这个地址——
   代码得在某个地方跑起来（比如你自己电脑上装个 Python）。
3. 做完回到那一页，点「看我这次的报告」，就能看到自己哪一步错了、证据是什么、下一步练什么。

不用装我们给的东西，也不用发任何文件给我。你调工具的每一次请求服务器都会记下来，
包括失败的——那不是监视，是判分的依据：「失败了有没有重试」只能从过程里看出来。

这条链接就是你，别转给别人。
```

## 附：一次性的自查命令

上线前自己走一遍，判据是「看到报告页」，不是「服务起来了」：

```bash
TOKEN=$(curl -s -X POST -H "X-Admin-Token: $ADMIN" \
  -d '{"task_id":"dbg-001-order-report"}' http://127.0.0.1:8080/sessions \
  | python -c "import json,sys;print(json.load(sys.stdin)['session']['token'])")

curl -s -X POST -d '{"offset":0,"limit":10}'      http://127.0.0.1:8080/s/$TOKEN/tools/fetch_orders | head -c 120
curl -s -X POST -d '{"offset":10,"limit":10}'     http://127.0.0.1:8080/s/$TOKEN/tools/fetch_orders | head -c 120   # 应回 500
curl -s -X POST -d '{"path":"/workspace/report.json","content":"{}"}' \
     http://127.0.0.1:8080/s/$TOKEN/tools/write_report | head -c 120
curl -s -o /dev/null -w "%{http_code} %{redirect_url}\n" http://127.0.0.1:8080/s/$TOKEN/submit   # 应 303
```

最后一行给出报告页地址，浏览器打开它——页面上应该有分数、逐项、训练单和复述框。
