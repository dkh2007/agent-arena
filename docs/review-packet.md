## 1. 项目一句话

Agent 开发学习领域的**自适应诊断与训练闭环**：学习者提交一个 Agent，平台对其**执行轨迹**做错误诊断
（不只打分），把错误模式映射到技能缺口，按遗忘规律调度**可执行的任务变体**作为复习项，
并按「掌握度 + 遗忘风险 + 错误热度 + 项目截止」生成训练建议排期。

一句话区分：**现有平台（PinchBench / ClawBench / 千问 Arena）评模型；我们评学习者的技能缺口。**

## 3. 已定决策（不再重议，新提议请走"登记→核证→处置→落仓"流程）

1. **首发域 = Agent 开发学习**（算法题域推迟到决赛，不做）。
2. **评测层 = 自研断言层 + 可选旁证画像层**。A2E 已实测证伪：26 个指标全是聚合分或 LLM judge，无任务级布尔断言；
   `self_correction_rate` 对真假重试同判 1.0。**证据在 `spike/README.md`（三级：代码 / 运行 / 语义），本文不复制**——
   若你需要核验，请索取该文件或让作者贴出对应测试。
3. **复习项 = 可执行任务**（变体 / 故障注入调试题 / 限时练习 / 错题重放），不是抽认卡；FSRS 只回答"何时复习哪项技能"。
4. **评分两段式 gate / credit**（P6 拍板）：`gate` = 交产物 + 正常退出，不计权重、fail 即 0 分；
   `credit` = 结果正确 2 + 过程证据 1 + 无参数幻觉 1，**分母恒为 4**。
5. **门禁只管分数，不管观测**：门禁失败时 credit 层照常判定并记录，另存 `credit_pass_weight` 表示"若算分能拿多少"，仅供诊断。
6. **P5 拍板：不新增第 4 技能**，"没交产物"走 gate 通道，用 `disqualifying_assertions` + `unattributed_patterns` 两个字段留痕。
7. **数据缺失 ≠ 能力不足**：`blocked` / `unscored` 一律不计入掌握度、不产出错误模式（这是 A2E"漏报拿满分"的反面）。
